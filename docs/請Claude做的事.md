# 請 Claude 做的事

需要改程式碼、改資料庫、或做重算的事情，都在這裡。**你不需要會寫程式**，
照著範本描述需求就可以。

## 開始之前

1. 在**專案資料夾**（`ghg-platform`）開啟 Claude Code，不要在別的地方開
   —— 這樣它才讀得到 `CLAUDE.md` 裡的專案規則
2. 講清楚「要什麼結果」，不要講「怎麼改」。Claude 會自己找檔案
3. 它動手前會說明要改什麼，**看不懂就問它，確認了再讓它做**
4. 改完它會 build、重啟、push。如果它沒做，提醒它一句

## 常用指令範本

直接複製，把 `【】` 裡的內容換成你的。

### 更新排放係數並重算舊資料

```
請幫我更新【2027】年度的【台灣電力】係數，新的值是【0.474 kgCO2e/kWh】，
資料來源是【台灣電力公司 2027 年公告】。

更新後請把已經填報過的記錄一併重算（我知道 recalculate 只補 NULL，
要先把受影響記錄的 co2e 設成 NULL 再重算）。

重算前請先告訴我會影響幾筆記錄、哪些廠、哪些年度。
```

### 合併兩個以上的廠

```
請幫我把【CAB_MK1、CAB_MK2、CAB_MK5】合併成【CAB_MK】。

我知道這要寫一支 migration，請比照 db/migrations/V23__merge_factories.sql 的做法：
把 activity_records、emission_factor_assignments、rec_certificates 都轉到新廠，
處理重複，再刪掉舊廠。

動手前請先告訴我各廠有幾筆資料、合併後會變成幾筆。
做完請跑 scripts/verify-v32.mjs 確認名冊沒問題。
```

### 追某個數字為什麼不對

```
【集團碳排彙整表】的【2026 年】【NVN_MK】的【範疇二】顯示【4732】，
但我算出來應該是【5100】。

請幫我追這個數字是怎麼算出來的，從填報記錄一路查到畫面。
先不要改任何東西，找到原因先告訴我。
```

### 新增一個排放源

```
請幫我新增一個排放源：
- 代碼：【1-1A-10】
- 中文名：【鍋爐-天然氣】
- 範疇：【1】
- 預設單位：【Nm3】
- 是否生質：【否】

新增後請提醒我要去建哪些排放係數。
```

### 報表要多一個欄位／改排版

```
請幫我在【盤查清冊 Excel 的集團碳排彙整表分頁】加上【各廠人力數】這一欄，
放在【廠名下方】。

這是對外報表，請你改之前先匯出一份現況的 Excel 存檔，改完之後逐欄比對，
確認其他欄位的數字都沒變。
```

### 資料庫搬到內網 192.168.6.100

```
請幫我把資料庫從 Neon 搬到內網的 192.168.6.100。
Port 已經開通了。

請照 README.md 裡「資料庫搬遷到內網」那一節的步驟做，
每一步做完先讓我確認再繼續。搬完要比對 /summary 跟 /reduction 的數字
和搬遷前一致。
```

### 平台壞掉了

```
【減碳績效追蹤頁】打開之後【出現錯誤畫面】。

請幫我找出原因並修好。修之前先告訴我是什麼問題。
```

## ⚠️ 這些事不要自己動，一定要透過 Claude 並且看懂再放行

| 事情 | 為什麼 |
|------|--------|
| 直接連資料庫下 SQL 改資料 | 沒有紀錄、沒有交易保護、算過的 co2e 不會跟著更新 |
| 修改 `db/migrations/` 裡**已經套用過**的檔案 | 別台機器不會重跑，資料庫會分岔 |
| 手動改 `schema_migrations` 表 | 這是 migration 的版本紀錄，改了會重複執行或漏執行 |
| 合併或刪除有資料的廠 | 牽涉跨表搬資料，錯了很難回頭 |
| 改係數後不做重算 | 畫面會顯示舊數字而且**不會報錯**，最容易漏 |
| 把 `.env.local` 或密碼 commit 進 git | 資安事故 |
| 客戶 tech pack、報價、成本、訂單、個資寫進提示或 commit | 違反公司規範 |

## 大事之前先備份

要做重算、合併廠、搬資料庫這類事情之前，請 Claude 先做一份備份：

```
動手之前，請先幫我備份資料庫（pg_dump），把備份檔放到【路徑】，
並告訴我檔案大小，確認備份成功再繼續。
```

Neon 另外有內建的時間點還原，可以從 Neon 主控台開一個還原到指定時間的分支。

## 交接檢查清單

接手的人第一次上手，建議照這個順序熟悉：

- [ ] 讀 `README.md`，在自己電腦把平台跑起來（`npm run dev`）
- [ ] 讀 `docs/維運手冊.md`
- [ ] 在**測試**環境新增一個假廠 `TST_XXX`，確認它出現在首頁與彙整表，再刪掉
- [ ] 跑一次 `node scripts/inspect-registry.mjs` 看目前有哪些廠與排放源
- [ ] 跑一次 `node scripts/migrate.mjs --dry-run` 確認沒有待套用的 migration
- [ ] 匯出一次盤查清冊 Excel，確認打得開
- [ ] 確認自己拿得到：git 存取權、`.env.local` 的資料庫密碼、192.168.6.102 的 pm2 操作權限
