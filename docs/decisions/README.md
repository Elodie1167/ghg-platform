# 決策紀錄（Decision Log）

這裡記的是「為什麼」，不是「做了什麼」——做了什麼看 `git log` 和 migration 檔名就知道，
但為什麼選這個做法、範圍砍在哪裡、誰拍的板，只有這裡有。

目的：下一個接手的人（或下一個 Claude session）不必重新問一輪，就能知道現況與背後理由。

## 什麼時候要新增一筆

- 動到資料庫結構（新的 `V<n>__*.sql`）
- 改變一個既有規則（例如「停用改成刪除」「權限模型改了」）
- 做了取捨、砍了範圍、或刻意不做某件看起來該做的事
- Elodie 拍板了一個有截止日期或有爭議的決定

一般小 bug fix、UI 調整不需要寫（git commit message 夠了）。

## 格式

複製 `_template.md`，檔名 `NNNN-簡短英文或拼音描述.md`（數字遞增），填四段：
**背景 / 決定 / 為什麼 / 現在還沒做的**。
